# HTML学习笔记



### 1.HTML基本概念

什么是html(Hyper Text Markup Language) 用我自己的话说就是一个能挂载多种文件的使用协议。

### 2.HTML实践

从零搭建一个HTML页面，源码如下

`<!doctype html>
<html lang="zh-CN">

<head>
  <meta charset="utf-8">
  <title>示例页面</title>
</head>
<body>

  <p>你好，HTML！</p>
</body>
</html>`

然后这就是一个标准的静态网页。仅需要一个前端服务器就能实现，不需要PHP中间件和数据库。

如果想制作一个表单，那就得完成前端后端的交互。

### 3.基本语法

- **<html>** 元素是 HTML 页面的根元素
- **<head>** 元素包含了文档的元（meta）数据，如 **<meta charset="utf-8">** 定义网页编码格式为 **utf-8**。
- **<title>** 元素描述了文档的标题
- **<body>** 元素包含了可见的页面内容
- **<h1>** 元素定义一个大标题
- **<p>** 元素定义一个段落

### 4.与网安的联系

html是黑客拿到url第一呈现在眼前的东西，但黑客真正关注的不是内容而是接口。例如html表单和输入

- `<form>` 元素用于创建表单，`action` 属性定义了表单数据提交的目标 URL，`method` 属性定义了提交数据的 HTTP 方法（这里使用的是 "post"）。

- `<label>` 元素用于为表单元素添加标签，提高可访问性。

- `<input>`（不用写结束标签） 元素是最常用的表单元素之一，它可以创建文本输入框、密码框、单选按钮、复选框等。`type` 属性定义了输入框的类型，`id` 属性用于关联 `<label>` 元素，`name` 属性用于标识表单字段。

而"GET"则代表信息是从可见的URL地址栏里发送出去的，显然POST方法更安全。

button 与 input 差不多，都是提供一个按键用于完成文件上传的功能，

同时也是黑客最喜欢的html元素之一，这是这不起眼小按钮提供了黑客与前端交互的窗口，从而产生很多有意思的事情。

可见正是这html表单的作用让黑客从前端触及到数据库。
